Tansu Privacy Policy

Data Not Collected

Effective Date: 2026-11-22 · Applies to Tansu for iOS & iPadOS (com.cyx.tansu)

Summary: Tansu is a 100% offline local file manager, archive utility, and document reader. We do not collect, store, transmit, sell, or share any personal data, user files, analytics, or crash reports.

1. Data Collection

Tansu collects zero personal data. In accordance with Apple App Store privacy guidelines, Tansu declares Data Not Collected. There are no user accounts, no cloud syncing, no advertising networks, and no third-party analytics or telemetry SDKs.

2. Local-Only File Storage

All files you import, organize, extract, preview, or pack remain exclusively on your device inside Tansu's app sandbox and local App Group container (group.com.cyx.tansu). Deleting a file in Tansu permanently removes it from local storage.

3. Wi-Fi Transfer (Local Network Only)

When you explicitly enable Wi-Fi Transfer, Tansu starts a temporary local HTTP server on your current Wi-Fi network protected by a one-time 6-digit passcode. Files transfer directly between your device and your browser over your LAN and never pass through external servers. The server stops automatically when you leave the Wi-Fi Transfer screen or background the app.

4. Passwords, Passcodes & Biometrics

  • Archive passwords and Wi-Fi Transfer passcodes are held only in volatile memory during active operations and are never written to disk, UserDefaults, or logs.
  • Optional App Lock uses Apple's on-device LocalAuthentication framework (Face ID, Touch ID, Optic ID, or Device Passcode). Tansu never receives or stores biometric data.

5. Device Permissions

  • Photos (Read / Add Only): Used solely when you import media from Photos or export images, videos, and Live Photos back to your Photo Library.
  • Local Network: Used solely when you start Wi-Fi Transfer on your local network.
  • Face ID / Touch ID: Used solely when you enable optional App Lock in Settings.

6. Offline WebView Protection

Built-in Markdown and eBook readers (EPUB, FB2, MOBI, AZW3, CHM) render local files strictly offline and block outbound network requests.

7. Contact

If you have questions about this Privacy Policy, please contact the developer via the support contact listed on the Tansu App Store page.

Tansu 隐私政策

不收集任何数据

生效日期：2026-11-22 · 适用于 Tansu iOS / iPadOS 版（com.cyx.tansu）

摘要：Tansu 是一款 100% 离线的本地文件管理、解压打包与电子书阅读工具。我们不收集、不存储、不传输、不出售也不共享任何个人数据、用户文件、使用统计或崩溃日志。

1. 数据收集声明

Tansu 不收集任何个人数据，与 App Store 隐私标签「不收集数据（Data Not Collected）」完全一致。本应用无账号体系、无云端同步、无广告、无第三方统计或追踪 SDK。

2. 纯本地存储

您导入、一键归组、解压、预览或打包的所有文件均仅保存在设备本地的 App 沙盒与本地 App Group 容器（group.com.cyx.tansu）中。在 Tansu 内删除文件即直接从本地移除。

3. Wi-Fi 传输（仅局域网）

仅当您手动开启 Wi-Fi 传输时，Tansu 才会在当前局域网内启动临时本地 HTTP 服务，并由 6 位一次性口令保护。文件在您的设备与浏览器之间点对点传输，不经过任何外部服务器；离开传输页面或退回后台时服务会自动关闭。

4. 密码、口令与生物识别

  • 压缩包密码与 Wi-Fi 传输口令仅在当次操作的内存中短暂保存，绝不写入磁盘、UserDefaults 或日志。
  • 可选的应用锁功能完全依赖 Apple 设备端 LocalAuthentication（面容 ID / 触控 ID / 设备密码），Tansu 不会获取或存储任何生物特征数据。

5. 系统权限说明

  • 相册权限：仅在您主动从相册导入或导出图片、视频、实况照片时使用。
  • 本地网络权限：仅在您主动开启局域网 Wi-Fi 传输时使用。
  • 面容 ID / 触控 ID：仅在您在「更多 → 安全」中手动开启应用锁时使用。

6. 联系我们

如对本隐私政策有任何疑问，请通过 Tansu 在 App Store 商店页面提供的开发者支持联系方式与我们联系。
